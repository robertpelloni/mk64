# Project Memory & Observations

## Codebase Patterns
- Functions prefixed with `func_800` are typically unnamed routines translated directly from MIPS assembly. Finding matching calls and renaming them is a core ongoing task.
- Fixed-point matrix conversions (e.g. within `src/racing/math_util.c`) are heavily susceptible to precision-loss crashes (PU crashes) when converting N64 float semantics to integers.
- The global build config relies heavily on `tools/` (specifically `torch` and `decomp-permuter`) to format the assets JSON and align the linker (`mk64.ld`).

- Audio command queue in `src/audio/port_eu.c` dispatches commands via ring buffer `sAudioCmd` using `audio_cmd_queue_push_*`, flushes to the audio thread via `audio_cmd_queue_flush`, and unpacks in the RSP task runner via `audio_cmd_queue_process`. Sequence fade-in handled via `seq_player_fade_in`.
- Global audio mute and pause behaviors: `audio_set_pause_mute` triggers mute on game pause and unmutes on resume, setting `D_800EA16C`. `audio_mute_sfx_enable` and `audio_mute_sfx_disable` control sound effects during award ceremonies and sequence intros via `D_800EA108`. `audio_clear_sound_banks` clears channels 3 and 5.
- Kart engine sound system in `src/audio/external.c`: `audio_play_kart_engine_idle` configures engine rev audio per character parameters in `D_800E9F7C`. `audio_play_kart_engine_driving` initiates the active driving engine sound loop. `audio_stop_kart_engine_sound` kills engine audio channels. `audio_update_player_submerged_sound` coordinates water fall-off voicelines and splashes when karts enter fluids. `audio_update_player_lightning_distortion` modulates channel audio when shocked.
- Environmental audio and race progression: `audio_play_final_lap_fanfare` handles final lap transition music and speedup. `audio_set_player_tunnel_reverb` / `audio_clear_player_tunnel_reverb` adjust player reverb offsets in `D_800E9F7C[arg0].unk_14` along track tunnel sections. `audio_set_cpu_tunnel_reverb` / `audio_clear_cpu_tunnel_reverb` manage the same for CPU vehicles in `D_800EA06C`.
- Audio initialization and resets: `audio_init` initializes the audio system before entering the main loop in `main.c`. `audio_soft_reset` resets audio sessions, sound banks, and channel states. `audio_reset_state_and_cameras` re-zeroes camera tracking and tire surfaces.
- Race finish audio handling: `audio_trigger_race_finish` marks a player's finish state in `D_800EA0EC` and starts timer `D_800E9EA4`. `audio_update_race_finish_sequences` ticks this timer, triggering rank-based win/loss fanfares (`play_sequences`) and results screen music.
- Sequence command buffer: `audio_push_sequence_command` buffers commands to `D_80192CD0`. `audio_process_sequence_commands` flushes this buffer in each audio loop tick. `audio_fade_out_all_sequences` sends fadeout commands to players 0 and 1.
- Sequence player parameter management: `audio_reset_all_sequence_player_settings` reinitializes sequence players 0..2 properties and tempo parameters. `audio_reset_soft_sequence_player_settings` performs soft resets. `audio_set_sound_banks_enabled_mask` toggles sound banks, and `audio_clear_sound_channel_active_bit` restores sequence volume once active sound effects extinguish.
- Menu screen transition handlers: `set_menu_fade_main`, `set_menu_fade_main_alt`, `set_menu_fade_back`, `set_menu_fade_demo`, `set_menu_fade_data`, and `set_menu_fade_option` trigger standardized 10-frame screen fades while updating `gMenuFadeType`.
- Screen transition faders in `src/menu_items.c`: `start_screen_fade_out` (type 2) and `start_screen_fade_in` (type 1) control full-screen transition fades on transition channel 4. `start_channel_fade_in` / `start_channel_fade_out` control per-player viewport transitions in splitscreen mode. `start_screen_mosaic_fade_out` handles pixelation fades using `sTKMK00_LowResBuffer`.
- Controller Pak 1 & 2 probing and ghost save operations: `probe_controller_pak_1` and `probe_controller_pak_2` in `src/save.c` coordinate device checks and file handle initializations (`osPfsInitPak`/`osPfsInit`). `save_ghost_header_to_pak` writes out `struct_8018EE10_entry` with checksum, while `calculate_ghost_page_checksum` validates 256-byte ghost stream pages in `gReplayGhostCompressed`. Ghost headers are read and verified via `load_and_validate_pak1_ghost_headers` and `load_and_validate_pak2_ghost_headers`, supported by `calculate_pak1_ghost_header_checksum` and `calculate_pak2_ghost_header_checksum`. Ghost file allocation and header initialization are handled by `allocate_pak1_ghost_file` and `clear_and_write_pak1_ghost_header`.
- Audio course track setup and race completion flags: `audio_init_course_sequence` initializes channel volumes and dispatches course-specific sequence commands (`0xF0000000 | seqId`). Player race completion state is signaled by `audio_set_player_finish_state` (`D_800EA0EC[playerIndex] = 2`) and `audio_set_race_finish_flag` (`D_800EA0F4 = 1`).
- Sequence player command dispatch and execution: `seq_player_play_sequence` and `seq_player_stop_sequence` send sequence playback/stop commands (0x82/0x83). `audio_execute_sequence_command` processes the command stream. Sequence status is queried via `seq_player_get_active_sequence_id` and `audio_is_sequence_command_pending`, with `seq_player_clear_queued_count` resetting the player sequence queue. Frame volumes are updated via `audio_update_sequence_players`, with targets set by `seq_player_set_volume_target` and cancellations handled by `seq_player_cancel_setup_operations`.
- Player voice banks and kart engine dynamics: `audio_init_player_sound_bank` sets up character-specific voice banks via opcode 0xF3. Kart throttle timers are updated via `audio_update_kart_throttle_timer` (`D_800E9E24` / `D_800E9E34`), throttle release / deceleration rev sounds are triggered by `audio_update_kart_engine_rev_sound`, and engine audio pitch ratios are computed dynamically by `audio_calculate_kart_engine_pitch` (`D_800E9E64`). Skid sound volumes (`audio_update_skid_sound_volume`), frequencies (`audio_update_skid_sound_frequency`), sound transitions (`audio_update_tyre_skid_sound`), and surface effect selection (`audio_determine_surface_skid_effect`) are modulated by tyre surface types and speeds.
- 3D spatial audio system: `audio_allocate_3d_sound_node` reserves a 3D audio node in linked list `D_8018EFD8`. Camera relative positions and yaw rotations are computed in `audio_calculate_sound_relative_camera_position`, Doppler shifts are calculated in `audio_calculate_doppler_pitch_shift`, and spatial audio frame updates are coordinated by `audio_update_3d_spatial_sounds`. Channel attenuation, reverb, and panning parameters are calculated and applied via `audio_calculate_distance_attenuation`, `audio_calculate_sound_reverb`, `audio_calculate_sound_panning`, `audio_calculate_random_pitch_variation`, and `audio_apply_sound_characteristics_to_channel`.
- Grand Prix rival character assignment: `select_grand_prix_rival_characters` in `src/cpu_vehicles_camera_path.c` handles assigning non-human rival racers across the field. `reset_cpu_camera_path_indices` reinitializes waypoint path tracker array `D_80164670`.
